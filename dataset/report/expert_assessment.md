# Экспертная оценка безопасности

## Область сканирования
Сканирование проводилось на локальном сетевом интерфейсе хоста (172.21.10.187) с соблюдением ограничений по скорости (--rate 100).

## Анализ результатов сканирования

### 1. Сетевая разведка (Nmap / Masscan)
- **Результат:** Все 1000 стандартных TCP-портов, а также целевые порты 22, 80, 443, 8080 находятся в состоянии `closed (conn-refused)`.
- **Экспертная оценка:** На исследуемом IP-адресе отсутствуют запущенные сетевые службы, принимающие входящие соединения. Сетевая поверхность атаки на момент проведения аудита равна нулю.

### 2. Аудит веб-приложений (Nikto / Nuclei)
- **Результат:** Сканеры веб-уязвимостей не зафиксировали открытых HTTP/HTTPS портов.
- **Экспертная оценка:** Риски, связанные с конфигурацией веб-серверов (отсутствие Security Headers, утечки файлов типа `.git`, устаревшие версии Nginx/Apache), отсутствуют.

## Заключение и рекомендации
1. **Текущее состояние:** Система находится в защищенном состоянии с минимальным уровнем риска (Hardened state).
2. **Рекомендации на будущее:**
   - При развертывании новых сервисов (например, Nginx или Docker-контейнеров) открывать только необходимые порты.
   - Настроить локальный файрвол (`ufw`) для явного разрешения только доверенного трафика.
   - На этапе разработки веб-приложений внедрять статический анализ кода (SAST) и использовать заголовки безопасности.
