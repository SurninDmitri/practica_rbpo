# Датасет аудита сетевой безопасности

Данный датасет содержит результаты комплексного сканирования безопасности сетевых служб и веб-компонентов.

## Структура каталога
- `data/scan_findings.csv` — сводная таблица результатов сканирования.
- `data/raw/` — оригинальные отчеты утилит Nmap, Masscan, Nikto, Nuclei.
- `meta/scan_findings.meta` — метаданные датасета и параметры проведенного аудита.
- `report/` — экспертная оценка, аналитический отчет и список источников.
